# Prism plugins

Optional WASM modules for Prism. Each folder is self-contained: a prebuilt
`.wasm` artifact, a sample `config/` and its own documentation.

- [pamas-s40](pamas-s40/) — PAMAS S40 particle counter, device driver
  (`prism:device@0.1`). Serial, 16 size channels, GOST 17216 class and
  measurement time. Prism 0.1.1 or newer.
