# Prism user documentation

Prism Community edition is free for projects with up to 128 active tags per
instance. Start with [01_getting_started/01_OVERVIEW.md](01_getting_started/01_OVERVIEW.md).

| Folder | What it covers |
|---|---|
| [01_getting_started](01_getting_started/01_OVERVIEW.md) | install, first run, `00_app.toml`, architecture, cheat sheet |
| [02_communication](02_communication/01_DEVICES.md) | Modbus, S7comm, OPC UA client/server, OPC DA, MQTT |
| [03_tooling](03_tooling/01_BENCH_TOOLS.md) | `prism-sim`, `prism-dbg`, `prism-scan`, `prism-sniff`, `prism-devtools` |
| [04_logic](04_logic/01_RHAI.md) | Rhai scripts, alarms, service tags |
| [05_wasm](05_wasm/01_PLUGIN_SDK.md) | compute, device, ML and report plugins; ADRC |
| [06_operations](06_operations/01_LICENSING.md) | licensing and Windows/Linux/macOS deployment |

Developer material (plans, build guides, protocol notes) lives in `docs/dev/`
and is not part of the user release.
